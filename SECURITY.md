# Security Policy

**Please don't open a public issue or PR for a security problem.** Report it privately instead:

- **Preferred:** [open a private advisory](https://github.com/hcompai/hai-agents-python/security/advisories/new) on `hai-agents-python`, where the `holo` CLI lives. Installer issues: [advisory on this repo](https://github.com/hcompai/holo-desktop-cli/security/advisories/new).
- **Or email:** [compliance@hcompany.ai](mailto:compliance@hcompany.ai).

Include what you did, what happened, the platform, and a proof-of-concept if you have one. We acknowledge reports within 3 business days.

Fixes land on the latest release only. The security model is documented in [Security and privacy](https://hub.hcompany.ai/agents-api/cli/security).
